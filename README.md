# Streamlit Clear Blue-style Interactive Sphere — Version 3

Changes from Version 2:
- Removed the solid/blue atmospheric outer sphere.
- Removed the filled globe/core.
- Sphere is now made primarily from transparent particles and bright nodes.
- Reduced orbital-line opacity.
- Camera moved back and field of view widened so the sphere is not clipped.
- Transparent WebGL canvas/background.
- Designed for the Streamlit review page.

Run:
    pip install -r requirements.txt
    streamlit run app.py
